Classify8 Help

Thank you for using Classify8.
This page explains how to use each window and how to write search conditions and tags. Click an item in the menu on the left to jump to it.

Overview

Classify8 is a sorting tool that automatically moves or copies files and folders, based on flexible conditions written in its own search syntax.
It can run periodically in the background from the notification area (system tray), and it safely checks for identical files and resolves conflicts when a file with the same name already exists.

💡 Moving folders between drives
When you move a whole folder to a different drive (for example, from drive C to drive D), the tool automatically switches to a safe method: it copies the contents first, and then deletes the original folder.

Main Window

In the dashboard (main window), you manage the list of sort rules and run them.

Working with the list

  • Multiple selection: Hold Ctrl or Shift and click to select multiple rules.
  • Toggle several rules at once: With multiple rows selected, click any of their check boxes to enable or disable all selected rules at once.
  • Drag and drop: Drag a rule to change the order. (You can drag a row even if it is not selected. If multiple rows are selected, they are moved together.)
  • Right-click menu: Besides editing and copying rules, you can choose Open Source Folder / Open Destination Folder. (If the path contains tags, the nearest parent folder that can be resolved is opened.)

Keyboard shortcuts

  • Ctrl + C : Copies the selected rules.
  • Ctrl + X : Cuts the selected rules. (They are moved to the new position when you paste them. Until then, they stay in the list.)
  • Ctrl + V : Pastes the copied or cut rules above the currently selected row.
  • Delete : Deletes the selected rules.

Running rules

  • Double-click: Immediately runs only that one rule. (You can turn on a confirmation before it runs in the options.)
  • Run All Rules: Runs all enabled rules. When you run rules manually, a progress window is shown, and you can stop the process with Stop (Cancel).

Editing a Sort Rule

Click + Add Rule or Edit in the main window to open the rule editor.

Main settings

  • Source / Destination: The folder to search for files, and the folder to move (or copy) them to. With Use a preset, you can manage frequently used folders in one place.
  • Copy mode: By default, files are moved (the original disappears). Check Copy instead of moving to keep the original and create a copy.
  • Search condition: Describes which files to pick up. (See the next section for the syntax.)

Option tabs

  • General: Whether to ignore differences in case, full-width/half-width characters, and hiragana/katakana, and whether to target files only, folders only, or both.
    • Ignore full-width/half-width differences also treats other forms of the same character as identical, such as ligatures (ﬁ → fi), Roman numerals (Ⅳ → IV), and circled numbers (① → 1), in addition to full-width/half-width letters, digits, and katakana.
    • Characters that look the same but are stored differently, such as é as one character and e + an accent mark (common in file names created on a Mac), are always treated as identical, regardless of these options.
  • Size Filter: Excludes files of a specified size (Bytes / KB / MB) or larger, or of a specified size or smaller.
  • Date Filter: Excludes files based on their modification date, either by a specific date (on/before or on/after) or by a relative period such as "7 days ago or earlier".

Search Conditions (Syntax)

This syntax is used to match file names and folder names.

Operator Meaning Example Matches
* ? Wildcards *.pdf All files with the .pdf extension
/& AND photo /& latest Names that contain both "photo" and "latest"
/| OR quote /| invoice Names that contain either "quote" or "invoice"
/! NOT *.txt /& /! discard .txt files whose names do not contain "discard"
/( ) Grouping /( A /| B /) /& C Names that contain "A" or "B", and also contain "C"
" " Words with spaces "MY DATA" Searches for "MY DATA" as a single keyword

Note: If there is no operator between keywords, /& (AND) is inserted automatically. Keywords separated by spaces are treated as separate keywords, so enclose a phrase that contains spaces in " ".

Note: A keyword matches if it appears anywhere in the file name (partial match).

Note: * matches zero or more characters, and ? matches exactly one character. ? counts emoji, flags, accented letters, and rare kanji such as "𠮷" as one visible character each.

Note: The Ignore full-width/half-width differences and Ignore hiragana/katakana differences options on the General tab also apply to search conditions.

Note: If a condition is written incorrectly (for example, a missing closing parenthesis), you are notified with an error when you save the rule.

Automatic Folders (Dynamic Tags)

If you include the following tags in the source or destination folder path, folders are created automatically to match the date and time of the run. (Tags are case-insensitive.)

  • /YYYY or /YY : Year of the run (e.g. 2026, 26)
  • /MM : Month of the run (e.g. 09)
  • /DD : Day of the run (e.g. 15)
  • /NAME : The rule name entered in the rule editor
  • /COND : The search condition text (the / character, which cannot be used in paths, is removed automatically)
▼ Tags available only in the destination
These tags read the actual modification date of each file and sort by it.
You can use /FYYYY (year), /FMM (month), and /FDD (day).

Preset Manager

You can register frequently used folder paths under a name (alias), such as "Main Photos Folder". When you change the path of a preset, the change immediately applies to every rule that uses it.

Note: If you try to delete a preset that is in use, a safeguard lets you choose either to convert the rules to use the folder path directly (keeping the rules working) or to force the deletion.

Sort History

Choose [Sort] > [Sort History] from the menu to see a list of past results.
Right-click a row in the history to do the following:

  • Open Source Folder / Open Destination Folder: Opens File Explorer with the target file already selected and highlighted.
  • Open Rule: Jumps directly to the editor of that rule.

Global Settings (Options)

Choose [Options] > [Settings] from the menu to change how the whole application behaves.

Name Conflicts

Decides what to do when a file with the same name already exists in the destination, separately for when the sizes are the same and when they are different. (As a safety feature, a file is treated as identical even if its name differs only by a number such as (1), as long as the size matches and the timestamps differ by 2 seconds or less. Such files are quickly skipped or cleaned up.)

In addition, if you turn on If the sizes match but only the timestamps differ, compare the contents to check whether the files are identical, files with exactly the same content are also treated as duplicates (on by default). When the contents are the same, this takes precedence over the same-name handling above. This may take time for large files or slow drives.

Exclusions (global)

You can list files that should be ignored by the whole application (such as system files), one per line. The lines are combined with OR, and wildcards are available. Each line is treated as a single keyword, and spaces in a line are matched as they are.

Note: Exclusion keywords ignore case. Differences such as full-width/half-width, hiragana/katakana, ligatures, and Roman numerals are not ignored (the General options of rules do not apply here). Characters that differ only in how they are stored, such as é and e + an accent mark, are treated as identical.

Execution

When periodic execution is on, sorting runs automatically in the background at the specified interval (in minutes) while the application is minimized to the notification area.

Priority

Sets the priority of Classify8 (the Windows process priority). It decides whether Classify8 or other applications get preference when the CPU is busy. The setting takes effect as soon as you save.

  • High: Processes as fast as possible, ahead of other applications. Other applications may slow down while sorting is in progress.
  • Normal (default): The standard Windows priority.
  • Low: Gives preference to other applications. Recommended, for example, when periodic execution sorts many files while you are working.
  • Idle: Processes only when the PC is not busy with anything else. Sorting may take longer when the PC is busy.

Note: The priority applies to the whole application, so with Low or Idle, the Classify8 windows may also respond more slowly while the PC is busy.

Note: This setting mainly affects how CPU time is allocated. If most of the time is spent reading and writing files, changing the priority may not make much difference in speed.

Display (Language)

Selects the language used in windows and messages. The change takes effect as soon as you save (no restart is needed).

  • Auto (follow the OS language) (default): Uses the Windows display language. If that language is not available, English is used.
  • 日本語 / English: The languages built into the application.
  • Languages you add to the Languages folder also appear in the list.

Note: The help (this page) also opens in the selected language. If no help is available in that language, the Japanese help opens.

💡 Adding a language
Put a language file based on _template.json (for example, fr.json) in the Languages folder next to Classify8.exe, and then restart the application. For details, see README.txt in the same folder.

Safety features

  • A drive root searched together with its subfolders, and folders under Windows or Program Files, cannot be used as a source.
  • If you try to exit the application while sorting is in progress, it asks for confirmation, stops the process, saves the history, and then exits.
  • Settings, rules, and history are saved in the same folder as the executable (or in %AppData%\Classify8 if that folder is not writable). Unexpected errors are recorded in error.log.
