# Classify8 - Windows用ファイル自動振り分けツール

## 1. 機能概要

**「Classify8」** は、Windows環境で動作する高度なファイル/フォルダ自動振り分け・コピーツールです。
独自の柔軟な検索構文を用いて、ダウンロードフォルダや作業フォルダに散らばったファイルを自動で整理します。

### 主な特徴
* **独自構文による強力な検索**
  ワイルドカード(`*`, `?`)に加え、AND(` /& `)、OR(` /| `)、NOT(` /! `)、グループ化(` /(  /) `)を使った直感的な条件指定が可能です。
* **動的フォルダ生成**
  振り分け元/振り分け先パスに `{YYYY}` (年) や `{NAME}` (ルール名) などのタグを含めることで、実行時の日付などに合わせて自動的にフォルダを生成し分類します。
* **同名ファイルの競合解決**
  同名ファイルが存在した場合、「ファイルサイズ」「タイムスタンプ」を比較し、完全に同一とみなせる場合は不要な上書きを回避して元ファイルを削除します。サイズや日付が異なる場合は「新しいものを残す」「連番を付けてリネームする」などの柔軟な対応が可能です。
* **ステルス自動実行（タスクトレイ常駐）**
  タスクトレイに常駐し、指定した時間（n分）ごとにバックグラウンドで自動実行します。自動実行中は画面やエラーダイアログを一切出さず、他の作業を邪魔しません。

---

## 2. 動作環境・インストール方法

### 動作環境
* **OS**: Windows 10 / Windows 11 (64bit)
* **必須コンポーネント**: .NET 8.0 デスクトップランタイム (Windows Desktop Runtime 8.0)

### インストール・アンインストール方法
* **インストール**: 配布された `Classify8.zip` を解散し、任意のフォルダ（例: `C:\Tools\Classify8`）に配置するだけです。インストーラーによるレジストリ操作は行いません。
* **起動**: フォルダ内の `Classify8.exe` をダブルクリックして起動します。（※初回起動時に「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」を選択してください）
* **アンインストール**: フォルダごと削除するだけで完全にアンインストールされます。（設定はすべてフォルダ内の `.json` や `.csv` ファイルに保存されています）

## 3. 操作マニュアル

### 3.1 メイン画面（ダッシュボード）の操作
メイン画面では、振り分け条件（ルール）の一覧管理と手動実行を行います。

* **リスト操作**
  * **複数選択**: `Ctrl` や `Shift` を押しながらクリックで複数選択可能。
  * **一括チェック切替**: 複数行を選択した状態でいずれかのチェックボックスをクリックすると、選択中の全ルールの有効/無効が一瞬で切り替わります。
  * **ドラッグ＆ドロップ**: 選択したルールを掴んでドラッグすることで、順番を入れ替えられます（複数行の一括移動対応）。
* **キーボードショートカット**
  * `Ctrl + C` : ルールをコピー
  * `Ctrl + X` : ルールを切り取り
  * `Ctrl + V` : コピー・切り取りしたルールを貼り付け
  * `Delete` : 選択したルールを一括削除
* **実行操作**
  * ダブルクリック: クリックしたルール「だけ」を即座に実行します。
  * 「▶すべての条件で振り分け実行」: チェックが入っている有効なルールを上から順にすべて実行します。

### 3.2 振り分け条件（ルール）の追加・編集
メイン画面で「＋ ルール追加」または「編集」を押すと設定画面が開きます。

#### 【メイン項目】
* **振り分け元 / 振り分け先**: ファイルを探す場所と、移動(コピー)する場所を指定します。「プリセットを使用」にすると、よく使うフォルダを一元管理できます。
* **コピーモード**: デフォルトは「移動（元ファイルが消える）」ですが、「コピー」にチェックを入れると元ファイルを残したまま複製します。
* **検索条件**: 抽出したいファイルの条件を記述します。（※構文の詳細は第4章を参照）

#### 【オプションタブ】
* **一般**: 大文字/小文字や全角/半角の区別（揺れ吸収）の有無や、対象をファイルのみにするかフォルダのみにするかを設定します。
* **ファイルサイズ限定**: 指定したサイズ（Byte / KB / MB）の「以上」または「以下」のファイルを処理対象から除外できます。
* **タイムスタンプ限定**: ファイルの更新日時が指定日より古いもの、または「7日以前」といった相対時間で除外できます。

### 3.3 プリセット管理
よく使うフォルダパスを「メイン画像フォルダ」などの名前（エイリアス）で登録しておくことができます。登録したプリセットの中身を変更すると、それを使用しているすべてのルールに即座に反映されます。

### 3.4 振り分け履歴
メニューの `[振り分け(_S)] > [振り分け履歴]` から、過去の実行結果を一覧確認できます。
履歴の行を**右クリック**することで、以下の操作が可能です。
* 振り分け元フォルダを開く
* 振り分け先フォルダを開く
* **振り分けルールを開く**（対象ルールの編集画面に直接ジャンプします）

### 3.5 全体設定（オプション）
メニューの `[設定(_O)] > [オプション]` から、アプリ全体の挙動を変更できます。

* **同名ファイルの処理**: 
  振り分け先に既に同名ファイルが存在した場合の動作を決めます。
  （※Classify8は名前の末尾の `(1)` などの連番を無視し、サイズとタイムスタンプの誤差2秒以内であれば「完全に同一のファイル」と見なして高速でスキップ（移動時は元ファイル削除）する安全機能を備えています）
* **振り分けないファイル**:
  アプリ全体で無視したいファイル（システムファイル等）を改行区切りで指定できます。
* **実行条件（タイマー）**:
  「定周期で振り分けを実行する」をONにすると、アプリがタスクトレイに最小化されている間、指定した分間隔で自動的に振り分けが行われます。
* **レガシー移行 (特殊タブ)**:
  「ClassyNy」の設定CSVファイルを指定することで、Classify8用に自動最適化してインポートできます。

## 4. 検索条件・パス自動生成の独自構文仕様

### 4.1 検索条件（パーサー仕様）
Windowsのファイル名制限を考慮し、論理演算子には「スラッシュ（`/`）プレフィックス」を使用します。
* **`*`** : 任意の0文字以上
* **`?`** : 任意の1文字
* **`/&` (AND)** : かつ （※キーワード間に演算子がない場合は暗黙のANDとみなされます）
* **`/|` (OR)** : または
* **`/!` (NOT)** : 含まない
* **`/(  /)`** : グループ化して優先順位を指定します。

**(記述例)**
* `*.pdf /& /! 破棄`
  → 拡張子がPDFで、かつ名前に「破棄」を含まないファイル
* `/( 見積 /| 請求 /) /& 2026年`
  → 「見積」か「請求」のどちらかを含み、かつ「2026年」を含むファイル

### 4.2 動的パス生成タグ
振り分け元/振り分け先フォルダのパスに以下のタグを含めると、実行時に自動でフォルダを生成して分類します。（大文字/小文字は区別しません）
* **`/YYYY` , `/YY`** : 実行時の年（4桁, 2桁）
* **`/MM` , `/DD`** : 実行時の月、日
* **`/FYYYY` , `/FMM` , `/FDD`** : (振り分け先のみ) 対象ファイルが持つ更新日時（タイムスタンプ）の年・月・日
* **`/NAME`** : このルールの「設定名」
* **`/COND`** : このルールの「検索条件」の文字列（フォルダ名に使えない `/` は除去されます）

**(記述例)**
振り分け先を `D:\Backup\/YYYY\/NAME` に設定し、「画像退避」というルール名で2026年に実行した場合：
→ `D:\Backup\2026\画像退避\` フォルダが自動で作成され、そこにファイルが振り分けられます。
