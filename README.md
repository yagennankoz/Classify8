# Classify8 - Windows用ファイル自動振り分けツール

## 1. 機能概要

**「Classify8」** は、Windows環境で動作する高度なファイル/フォルダ自動振り分け・コピーツールです。
独自の柔軟な検索構文を用いて、ダウンロードフォルダや作業フォルダに散らばったファイルを自動で整理します。

### ✨ 主な特徴
* **独自構文による強力な検索**
  ワイルドカード(`*`, `?`)に加え、AND(` /& `)、OR(` /| `)、NOT(` /! `)、グループ化(` /(  /) `)を使った直感的な条件指定が可能です。
* **動的フォルダ生成**
  振り分け元/振り分け先パスに `/YYYY` (年) や `/NAME` (ルール名) などのタグを含めることで、実行時の日付などに合わせて自動的にフォルダを生成し分類します。
* **超高速・安全な並列処理エンジン**
  マルチコアを活用した並列処理と、一度読み込んだフォルダ構成を再利用するメモリキャッシュ機能により、数万ファイルの振り分けでも一瞬で完了します。（※異なるドライブ間のフォルダ移動も、自動で「コピー＆削除」に切り替えて安全に処理します）
* **同名ファイルのスマートな競合解決**
  同名ファイルが存在した場合、「ファイルサイズ」「タイムスタンプ」を比較し、連番違い等を含めて同一とみなせる場合は不要な上書きを回避して元ファイルをお掃除（削除）します。サイズや日付が異なる場合は「新しいものを残す」「連番を付けてリネームする」などの柔軟な対応が可能です。
* **ステルス自動実行（タスクトレイ常駐）**
  タスクトレイに常駐し、指定した時間（n分）ごとにバックグラウンドで自動実行します。自動実行中は画面を一切出さず、アイコンの点滅のみで静かに処理を行います。

## 2. 動作環境・インストール方法

### 動作環境
* **OS**: Windows 10 / Windows 11 (64bit)
* **必須コンポーネント**: .NET 8.0 デスクトップランタイム (Windows Desktop Runtime 8.0)

### インストール・アンインストール方法
* **インストール**: 配布された `Classify8.zip` を解凍し、任意のフォルダ（例: `C:\Tools\Classify8`）に配置するだけです。インストーラーによるレジストリ操作は行いません。
* **起動**: フォルダ内の `Classify8.exe` をダブルクリックして起動します。
* **アンインストール**: フォルダごと削除するだけで完全にアンインストールされます。

## 3. 操作マニュアル

### 3.1 メイン画面（ダッシュボード）の操作
* **リスト操作**
  * **複数選択**: `Ctrl` や `Shift` を押しながらクリックで複数選択可能。
  * **一括チェック切替**: 複数行を選択してチェックボックスをクリックすると、全ルールの有効/無効が一瞬で切り替わります。
  * **ドラッグ＆ドロップ**: 選択したルールを掴んでドラッグすることで、順番を入れ替えられます。
* **キーボードショートカット**
  * `Ctrl + C` : ルールをコピー
  * `Ctrl + X` : ルールを切り取り
  * `Ctrl + V` : コピー・切り取りしたルールを選択行の**上**に貼り付け
  * `Delete` : 選択したルールを一括削除
* **実行操作**
  * ダブルクリック: クリックしたルール「だけ」を即座に実行します。
  * 「▶すべての条件で振り分け実行」: 有効なルールをすべて実行します。手動実行時は進捗ダイアログが表示され、途中で「キャンセル」も可能です。
* **右クリックメニュー**
  * ルールの編集やコピーのほか、**「振り分け元フォルダを開く」「振り分け先フォルダを開く」** ことが可能です（動的タグが含まれている場合は、展開可能な親フォルダを自動で開きます）。

### 3.2 振り分け条件（ルール）の追加・編集
#### 【メイン項目】
* **振り分け元 / 振り分け先**: ファイルを探す場所と、移動(コピー)する場所を指定します。「プリセット」を使用するとパスを一元管理できます。
* **検索条件**: 抽出したいファイルの条件を記述します。（※空白を含むキーワードは `" "` で囲んでください）

#### 【オプションタブ】
* **一般**: 大文字/小文字や全半角の揺れ吸収設定、対象タイプ（ファイル/フォルダ）の指定。
* **ファイルサイズ限定**: 指定サイズ以上のファイルを除外する等のフィルタ設定。
* **タイムスタンプ限定**: 「7日以前」や「特定の日付以降」などの相対/絶対時間による除外設定。

### 3.3 プリセット管理
よく使うフォルダパスを「メイン画像フォルダ」などの名前で登録できます。パスを変更すると、使用しているすべてのルールに即座に反映されます。

### 3.4 振り分け履歴
過去の実行結果を一覧確認できます。履歴の行を右クリックすると以下の操作が可能です。
* **振り分け元 / 先フォルダを開く**: エクスプローラーが開き、対象のファイルが自動的に選択・ハイライトされます。
* **振り分けルールを開く**: 対象ルールの編集画面に直接ジャンプします。

### 3.5 全体設定（オプション）
* **同名ファイルの処理**: 既に同名ファイルが存在した場合の動作（リネーム、スキップ、上書き等）を決めます。
* **実行条件（タイマー）**: 定周期実行をONにすると、タスクトレイ格納時に自動振り分けが行われます。
* **レガシー移行 (特殊タブ)**: 旧ツール「ClassyNy」の設定CSVを最適化してインポートします。

## 4. 検索条件・パス自動生成の独自構文仕様

### 4.1 検索条件（パーサー仕様）
* **`*`** : 任意の0文字以上 / **`?`** : 任意の1文字
* **`/&` (AND)** : かつ （※キーワード間は暗黙のANDとみなされます）
* **`/|` (OR)** : または
* **`/!` (NOT)** : 含まない
* **`/(  /)`** : グループ化して優先順位を指定
* **`" "`** : 空白を含むキーワードの指定 (例: `"PURPLE SKY"`)

### 4.2 動的パス生成タグ
振り分け先/元のパスに以下のタグを含めると、実行時に自動で展開・フォルダ生成されます。
* **`/YYYY` , `/YY`** : 実行時の年（4桁, 2桁）
* **`/MM` , `/DD`** : 実行時の月、日
* **`/FYYYY` , `/FMM` , `/FDD`** : (※振り分け先のみ) 対象ファイルの更新日時の年・月・日
* **`/NAME`** : このルールの「設定名」
* **`/COND`** : 検索条件の文字列（`/` は除去されます）
