# Classify8 - Windows用ファイル自動振り分けツール

## 1. 機能概要

**「Classify8」** は、Windows環境で動作する高度なファイル/フォルダ自動振り分け・コピーツールです。
独自の柔軟な検索構文を用いて、ダウンロードフォルダや作業フォルダに散らばったファイルを自動で整理します。

### 主な特徴
* **独自構文による強力な検索**
  ワイルドカード(`*`, `?`)に加え、AND(` /& `)、OR(` /| `)、NOT(` /! `)、グループ化(` /(  /) `)を使った直感的な条件指定が可能です。
* **動的フォルダ生成**
  振り分け元/振り分け先パスに `/YYYY` (年) や `/NAME` (ルール名) などのタグを含めることで、実行時の日付などに合わせて自動的にフォルダを生成し分類します。
* **高速・安全な並列処理エンジン**
  マルチコアを活用した並列処理と、一度読み込んだフォルダ構成を再利用するキャッシュにより、大量のファイルも高速に振り分けます。（※異なるドライブ間のフォルダ移動も、自動で「コピー＆削除」に切り替えて安全に処理します）
* **同名ファイルのスマートな競合解決**
  同名ファイルが存在した場合、「ファイルサイズ」「タイムスタンプ」を比較し、連番違い等を含めて同一とみなせる場合は不要な上書きを回避して元ファイルをお掃除（削除）します。サイズが同じでタイムスタンプだけ異なる場合も、内容を比較して中身が完全に同じなら重複として扱います（オプションでON/OFF可能）。サイズや日付が異なる場合は「新しいものを残す」「連番を付けてリネームする」などの柔軟な対応が可能です。
* **ステルス自動実行（タスクトレイ常駐）**
  タスクトレイに常駐し、指定した時間（n分）ごとにバックグラウンドで自動実行します。自動実行中は画面を一切出さず、アイコンの点滅のみで静かに処理を行います。
* **多言語対応**
  画面・メッセージ・ヘルプは日本語と英語に対応しています。言語ファイルを追加すれば、他の言語でも使えます。

## 2. 動作環境・インストール方法

### 動作環境
* **OS**: Windows 10 / Windows 11 (64bit)
* **必須コンポーネント**: .NET 8.0 デスクトップランタイム (Windows Desktop Runtime 8.0)

### インストール・アンインストール方法
* **インストール**: 配布された `Classify8.zip` を解凍し、任意のフォルダ（例: `C:\Tools\Classify8`）に配置するだけです。インストーラーによるレジストリ操作は行いません。
* **起動**: フォルダ内の `Classify8.exe` をダブルクリックして起動します。多重起動はできません（起動中の場合は、タスクトレイを確認してください）。
* **アンインストール**: フォルダごと削除するだけで完全にアンインストールされます。（書き込みできないフォルダに配置した場合は、`%AppData%\Classify8` も削除してください）

## 3. 操作マニュアル

詳しい操作方法は、メニューの「ヘルプ」>「操作ヘルプ」で表示されるヘルプ（`Help.html` / 英語版 `Help.en.html`）を参照してください。

### 3.1 メイン画面（ダッシュボード）の操作
* **リスト操作**
  * **複数選択**: `Ctrl` や `Shift` を押しながらクリックで複数選択可能。
  * **一括チェック切替**: 複数行を選択してチェックボックスをクリックすると、選択中の全ルールの有効/無効が一瞬で切り替わります。
  * **ドラッグ＆ドロップ**: ルールを掴んでドラッグすることで、順番を入れ替えられます（選択されていない行も、そのまま掴めます。複数行を選択している場合は、まとめて移動できます）。
* **キーボードショートカット**
  * `Ctrl + C` : ルールをコピー
  * `Ctrl + X` : ルールを切り取り（貼り付けた時点でその位置へ移動。貼り付けるまで一覧からは消えません）
  * `Ctrl + V` : コピー・切り取りしたルールを選択行の**上**に貼り付け
  * `Delete` : 選択したルールを一括削除
* **実行操作**
  * ダブルクリック: クリックしたルール「だけ」を即座に実行します。（オプションで実行前の確認ダイアログを表示可能）
  * 「すべての条件で振り分け実行」ボタン: 有効なルールをすべて実行します。手動実行時は進捗ダイアログが表示され、途中で「キャンセル」も可能です。
* **右クリックメニュー**
  * ルールの編集やコピーのほか、**「振り分け元フォルダを開く」「振り分け先フォルダを開く」** ことが可能です（動的タグが含まれている場合は、展開可能な親フォルダを自動で開きます）。
* **新規ルールの追加位置**: 「ルール追加」で作ったルールは、選択中の行の上に挿入されます。

### 3.2 振り分け条件（ルール）の追加・編集
#### 【メイン項目】
* **設定名**: ルールの名前です。振り分け先の `/NAME` タグにも使われます。
* **振り分け元 / 振り分け先**: ファイルを探す場所と、移動(コピー)する場所を指定します。「プリセット」を使用するとパスを一元管理できます。振り分け元は「サブフォルダも対象とする」を選べます。
* **コピーモード**: 「振り分け(移動)ではなく、コピーする」にチェックを入れると、元ファイルを残したまま複製します。
* **検索条件**: 抽出したいファイルの条件を記述します。（※空白を含むキーワードは `" "` で囲んでください）

#### 【オプションタブ】
* **一般**: 大文字/小文字・半角/全角・ひらがな/カタカナを区別するか、対象タイプ（ファイルのみ / フォルダのみ / ファイル＋フォルダ）、振り分け履歴に保存しないか、を指定します。
* **ファイルサイズ限定**: 指定サイズ（バイト / KB / MB）以下、または以上のファイルを振り分け対象から除外します。
* **タイムスタンプ限定**: ファイルの更新日時をもとに、「特定の日付以前/以降」や「7日以前」などの絶対/相対時間で除外します。

### 3.3 プリセット管理
よく使うフォルダパスを「メイン画像フォルダ」などの名前で登録できます。パスを変更すると、使用しているすべてのルールに即座に反映されます。
使用中のプリセットを削除する場合は、「個別指定に変換して削除」（各ルールにフォルダパスをコピーしてから削除）か「無視して強制削除」を選べます。

### 3.4 振り分け履歴
メニューの「振り分け」>「振り分け履歴」で、過去の実行結果を一覧確認できます。履歴の行を右クリックすると以下の操作が可能です。
* **振り分け元 / 先フォルダを開く**: エクスプローラーが開き、対象のファイルが自動的に選択・ハイライトされます。
* **振り分けルールを開く**: 対象ルールの編集画面に直接ジャンプします。

### 3.5 全体設定（オプション）
メニューの「設定」>「オプション」で、アプリ全体の動作を設定します。
* **同名ファイルの処理**: 振り分け先に同名ファイルが存在した場合の動作を、「サイズが同じ場合」と「違う場合」それぞれについて決めます（新しい日付のファイルを残す / 古い日付のファイルを残す / ファイル名を変えて振り分ける / 振り分けない）。「サイズが同じでタイムスタンプだけ異なる場合、内容を比較する」オプション（初期値ON）で、中身が同一のファイルを重複として扱えます。
* **振り分けないファイル**: アプリ全体で無視したいファイルのキーワード（NGキーワード）を、1行に1つずつ指定します。行どうしはOR条件になり、ワイルドカードも使えます。
* **実行条件**
  * **定周期実行**: ONにすると、タスクトレイ格納時に指定した分間隔で自動振り分けが行われます。
  * **その他の設定**（かっこ内は初期値）: ファイル削除時にごみ箱へ移動する（ON）、振り分け先フォルダがない場合に自動作成する（ON）、最小化で起動する（OFF）、読み取り専用ファイルの確認ダイアログを出さない（ON）、ダブルクリック実行前に確認する（OFF）、振り分け履歴の保存件数を制限する（ON・1000件。百件単位で指定）。
* **処理の優先度**: 振り分け処理のプロセス優先度を「高 / 通常（初期値） / 低 / アイドル」から選べます。低くすると、作業中に他のアプリの動作が重くなりにくくなります。
* **表示（言語）**: 表示言語を「自動（OSの言語に合わせる） / 日本語 / English / 追加した言語」から選べます。保存するとすぐに反映されます（再起動不要）。「自動」で対応する言語がない場合は英語になります。
* **特殊（レガシー移行）**: 旧ツール「ClassiNy」の設定CSVを最適化してインポートします。「共通」の振り分け元を使うルールは、プリセット「ClassiNy共通振り分け元」にまとめられ、パスを設定するまで無効の状態で取り込まれます。

### 3.6 安全機能・データの保存場所
* **安全機能**: ドライブ直下のサブフォルダ検索や、Windows / Program Files 配下のフォルダは、振り分け元に指定できません。処理の実行中に終了しようとすると、確認のうえ中止し、履歴を保存してから終了します。
* **データの保存場所**: 設定・ルール・履歴は実行ファイルと同じフォルダに保存されます（書き込めない場合は `%AppData%\Classify8`）。書き込み中の電源断などでファイルが壊れないよう、一時ファイル経由で保存し、読み込めないファイルはバックアップを残します。予期しないエラーは `error.log` に記録されます。
* **詳細設定（settings.json のみ）**: `ContentCompareMaxSizeMB` で、内容比較を行うファイルサイズの上限（MB）を指定できます。`0`（初期値）は無制限です。

### 3.7 言語の追加
`Classify8.exe` と同じ場所にある `Languages` フォルダに、`_template.json` をもとに作った言語ファイル（例: `fr.json`）を置き、アプリを再起動すると、表示タブの言語一覧に追加されます。手順の詳細は、同じフォルダの `README.txt` を参照してください。
* 日本語と英語はアプリに内蔵されています。`ja.json` / `en.json` を置くと、書かれているキーだけ内蔵の文字列を上書きできます。
* 翻訳されていないキーは、日本語で表示されます。
* ヘルプは表示言語に合わせて `Help.{言語コード}.html` が開きます（例: `Help.en.html`）。ない場合は `Help.html`（日本語）が開きます。

## 4. 検索条件・パス自動生成の独自構文仕様

### 4.1 検索条件（パーサー仕様）
* **`*`** : 任意の0文字以上 / **`?`** : 任意の1文字（絵文字や結合文字を含む文字も、見た目の1文字として数えます）
* **`/&` (AND)** : かつ （※空白で区切ったキーワード間は暗黙のANDとみなされます）
* **`/|` (OR)** : または
* **`/!` (NOT)** : 含まない
* **`/(  /)`** : グループ化して優先順位を指定
* **`" "`** : 空白を含むキーワードの指定 (例: `"PURPLE SKY"`)
* キーワードはファイル名の一部に含まれていれば一致します（部分一致）。
* 「大文字/小文字」「半角/全角」「ひらがな/カタカナ」を区別しない設定は、検索条件の判定に反映されます。「半角/全角を区別しない」は、合字（`ﬁ` → `fi`）、ローマ数字（`Ⅳ` → `IV`）、丸数字（`①` → `1`）なども同じ文字として扱います。
* 「が」と「か＋濁点」、「é」と「e＋アクセント記号」のように、見た目が同じで内部の表し方だけが違う文字（Mac で作られたファイル名などに多い）は、設定に関係なく同じ文字として扱います。
* NGキーワードは、大文字/小文字を区別せず、半角/全角・ひらがな/カタカナは区別します。
* 括弧の閉じ忘れなど、条件の書き方に誤りがある場合は、ルールの保存時にエラーでお知らせします。

### 4.2 動的パス生成タグ
振り分け先/元のパスに以下のタグを含めると、実行時に自動で展開・フォルダ生成されます。（大文字・小文字どちらでも可）
* **`/YYYY` , `/YY`** : 実行時の年（4桁, 2桁）
* **`/MM` , `/DD`** : 実行時の月、日
* **`/FYYYY` , `/FYY` , `/FMM` , `/FDD`** : (※振り分け先のみ) 対象ファイルの更新日時の年・月・日
* **`/NAME`** : このルールの「設定名」（フォルダ名に使えない文字は置き換えられます）
* **`/COND`** : 検索条件の文字列（`/` は除去されます）

## 5. 開発者向け情報

* **開発環境**: .NET 8 SDK（WPF, `net8.0-windows`）
* **ビルド**: `dotnet build`
* **テスト**: `dotnet test Classify8.Tests/Classify8.Tests.csproj`（xUnit + FlaUI）。UIテストは実際にアプリを操作するため、実行中はマウス・キーボードに触れないでください。UIテストを除く場合は `--filter "FullyQualifiedName!~FullUITests"` を付けます。詳細は `Classify8.Tests/README.md` を参照してください。
* **言語ファイル**: 内蔵の文字列は `Resources/Lang/{ja,en}.json`（アプリに埋め込み）です。XAML では `{loc:Tr キー}`、コードでは `Loc.T` / `Loc.F` で参照します。キーを追加・変更したら、`Languages/_template.json` も英語版と同じ内容にそろえてください。
